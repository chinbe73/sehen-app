# Sehen

Öffentliche, statische Bedienoberfläche der barrierearmen iPad-App. Die geschützte Dokumenterkennung läuft getrennt über eine Netlify Function; Zugangsdaten sind nicht in diesem Repository enthalten.

## Für eine spätere Ausbaustufe vorgemerkt

- Dokumenttypen ergänzend erkennen, ohne den optimierten Artikelmodus zu verändern.
- Rezepte anhand mehrerer Strukturmerkmale erkennen und Zutatenlisten sowie Arbeitsschritte passend darstellen und vorlesen.
- Vor der Umsetzung mit unterschiedlichen echten Rezeptseiten testen, insbesondere ein- und zweispaltige Layouts, Mengenangaben und Rezepte mit Bildern.
